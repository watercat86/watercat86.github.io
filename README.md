# HTML Games Collection

シンプルで遊べるHTMLゲームを集めたサイトです。友達と気軽に遊ぶために作りました。

## 🎮 収録ゲーム

- **ARCANUM ECHO** - やりこみ系超シンプルRPG
- **狂気の創作料理シミュレーター** - 狂った創作料理シミュレーター

今後もモチベがあれば、ゲームは随時追加予定です。

## 🚀 遊ぶ方法

インストールは不要です。以下のリンクにアクセスして、ブラウザで直接プレイできます：

[https://watercat86.github.io](https://watercat86.github.io)

## 🔧 改変について

改変・カスタマイズは自由です！ただし、以下の点だけお願いします：

- **ARCANUM ECHO** を改変する場合：セーブコードを元のシステムとは別にしてください（可能な範囲で）
- **狂気の創作料理シミュレーター** は特に制限なし。自由にやってOK
